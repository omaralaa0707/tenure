# Tenure: Design Context

## Current state (2026-07-26, final pass)

This file's job: let a future session pick up this site without Omar having to re-explain the reasoning behind decisions that are easy to second-guess out of context. Read this before touching design or positioning.

### What the site is, right now
Tenure designs, builds, and manages AI employees for founder-led service businesses. Each one gets its own workstation, its own company email, and the same access to the client's tools as any human hire, minus weekends and sick days. It handles repetitive junior-level work independently and can take on senior-level work with a human reviewing before it goes out. Priced as a setup fee, then a monthly fee. No gimmicky guarantee badge; the accountability language (a named person at Tenure owns the outcome, rebuilds or replaces underperforming work, no fixed deadline attached) is folded into prose instead.

Contact language points at "the team" / "Tenure," never at Omar by name. The mailto address is still his, but it's not surfaced as a founder-to-founder pitch.

### Visual system, right now
Single typeface (Schibsted Grotesk), OKLCH palette tinted toward a deep pine hue (152°). The site is **deliberately single-theme**: no light/dark toggle. A fixed, persistent dark backdrop sits behind the entire page: a **liquid-metal shader** (`@paper-design/shaders-react`, preset "Backdrop"), rendered in `app/Backdrop.js`. It replaced a canvas dot field, which replaced 48 static spans. The dot field was abandoned because it could not be made perceptible: even pushed to 30px/s it still read as texture rather than motion.

The preset ships grey with a white tint and a red/blue chromatic split. All of that is overridden to the backdrop and accent colors, so the surface reads as lit pine rather than chrome, and both chromatic shifts are zeroed.

Two constraints keep it usable behind a long page of text:

- **Brightness.** The raw shader washed body copy out completely. It is held at `opacity: 0.24` with a flat `--backdrop` scrim over it (a flat overlay, not a gradient; the no-gradients rule still stands). Verified by sampling *rendered pixels* behind each text block and measuring worst-case contrast against `--ink`. Computed styles cannot see a shader, so a normal contrast audit will report a false pass here.
- **Fill rate.** It is a full-viewport fragment shader, so cost scales with pixels drawn. At DPR 2 it rasterised ~5.2M per frame and ran at 8fps under software rendering. `maxPixelCount={960 * 540}` brings that to ~518k: 59fps software, 61fps with a GPU, and visually identical because the surface is a soft blur. Do not raise it without a frame-rate measurement.

A second shader, `app/WaveField.js`, appears exactly once, behind the closing statement. It is the raw-shader wave effect with two changes: it is scoped to its section rather than `position: fixed` (the original would have covered the page and fought the backdrop for the same pixels), and its red/green/blue channel split is summed into a single intensity mapped onto the pine ramp, since this site has one hue. A `yOffset` uniform drops the band low so the light reads as a horizon *under* the copy; centred, it put a bright stripe through the text and failed contrast at 2.63:1.

Both shaders freeze rather than unmount under `prefers-reduced-motion`, so the surface still reads as the same material instead of going flat black. Confirmed by screenshot diff: mean pixel difference 11.47 in normal motion, exactly 0 when reduced.

Because of the single-theme commitment, `--ink` / `--muted` / `--accent` etc. mean "on the dark backdrop" at `:root` and flip to "on light glass" inside `.glass`, so most component CSS never needed a per-rule rewrite when the pivot happened.

Favicon is `app/icon.svg`: the same abstract workstation glyph used in the hero (rounded window, chrome line, three content lines, a green cursor square), redrawn at favicon scale.

### History (why it looks like this and not something else)
Six-plus rounds before this state: too bland, then over-decorated, reverted, "looks like a weird document with a demo chat box," restructured, broadened, destigmatized, re-storied. That led to a full rebuild around a direct, outcome-first, not-product-first brief in Omar's own words, dropping an "employment paperwork" visual conceit (certificate borders, offer-letter language, a serif chosen to evoke legal printing) entirely rather than reskinning it.

After that rebuild landed, three more deliberate changes followed, each already reflected in "current state" above and not repeated here as open questions:
1. Repositioned from "inquiries going cold" to "a real employee with its own equipment," including the junior/senior-with-oversight split.
2. Removed Omar's name from all visible copy; killed the 90-day guarantee badge as gimmicky; renamed "hiring fee / salary" to "setup fee / monthly fee."
3. Added visuals and motion (icons, hero glyph, scroll reveal, live pulse), then the glass-over-backdrop pivot described above, then the favicon.

### Standing rules (still enforced every round)
- Zero em dashes anywhere in site copy or code comments.
- No CSS gradients, no gradient text, no bounce easing, no pure `#fff`/`#000`.
- `backdrop-filter` / glassmorphism is now an intentional, explicitly-chosen exception to what was previously a banned pattern. Do not silently re-ban it; if a future round wants cards flat again, that's a real design conversation, not a default.
- Compute OKLCH → sRGB contrast ratios before writing new color pairs, not after. Every text/background and control-border pair in the current palette has been verified against WCAG (4.5:1 text, 3:1 control borders) at write time.
- "Basically an agency" (an early instruction) describes the delivery model, not a license to use the word "agency" anywhere on the site. The locked brand decision to never say "agency" still stands.
